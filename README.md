# ModularDom Group

Web corporativa premium · React + Vite + TailwindCSS + Framer Motion.

## Desarrollo
```bash
npm install
npm run dev
```

## Producción
```bash
npm run build      # genera /dist
npm run preview
```

## Deploy en Vercel
1. Sube el repo a GitHub.
2. Importa el proyecto en Vercel (framework: Vite, detectado automáticamente).
3. Deploy.

## Personalización rápida
- **Cifras, marcas, proyectos, proceso:** edita `src/data.js`.
- **Formulario de contacto:** sustituye `your-id` en `App.jsx` por tu ID de Formspree.
- **Vídeo del hero:** cambia la URL del `<source>` en el componente `Hero` (`App.jsx`).
- **Colores y tipografía:** `tailwind.config.js`.
